Key System Behaviors — v3.0

🔄
01  ·  Data Synchronization
Autonomous Session-Scoped Sync
Sync is strictly conditional — dispatch assignments only restore when a valid matching incident exists in the current session.
Migrated from localStorage → sessionStorage. Assignments are wiped automatically when the browser tab closes — no ghost routes across sessions.
Mobile app uses NetInfo for connectivity detection. Offline reports queue to SQLite; auto-sync fires when connection restores.
Sync Flow
1. Tab opens → sessionStorage read → restore if incidents exist
2. Unit arrives → remove from sessionStorage
3. Tab closes → sessionStorage cleared by browser
4. New tab → clean state, no stale routes
📎
02  ·  Field Reporting
Polymorphic Media Attachments
Reports natively support Text, Images, and Videos independently or combined. No attachment is mandatory.
Mobile uses expo-image-picker v17 with Camera, Library, and Video pickers. Up to 5 files per report.
API endpoint upgraded to MultiPartParser + FormParser + JSONParser — single endpoint handles both text-only JSON and file uploads.
Response includes absolute file_url per attachment, built via request.build_absolute_uri().
📷 Camera capture 🖼 Photo library 🎥 Video library
🔐
03  ·  Security
Active JWT Role Mapping
JWT now maps functional operational roles directly to real-time client entities, replacing unlinked generic accounts.
Token payload embeds user_id, username, and role. Every authenticated request forwards X-User-ID and X-User-Role headers.
TaskPermission enforces fieldunit-only PATCH on tasks; dispatcher / admin have elevated rights enforced server-side.
Role → Permission Matrix
⬤ admin    → full CRUD all resources
⬤ dispatcher → read all + assign units
⬤ fieldunit → read tasks + PATCH own status
